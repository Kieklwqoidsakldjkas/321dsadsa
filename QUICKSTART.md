# 🚀 Быстрый старт

## Windows

### 1. Установка
```cmd
install.bat
```

### 2. Настройка
Отредактируйте файл `.env`:
```env
BOT_TOKEN=your_bot_token_here
```

### 3. Запуск
```cmd
run.bat
```

## Linux/Unix

### 1. Установка
```bash
sudo ./install.sh
```

### 2. Настройка
Отредактируйте файл `.env`:
```env
BOT_TOKEN=your_bot_token_here
```

### 3. Запуск
```bash
python run.py
```

## 📝 Минимальная конфигурация

Создайте файл `.env` с единственным параметром:
```env
BOT_TOKEN=your_bot_token_here
```

**Все остальное определяется автоматически:**
- ✅ IP сервера
- ✅ База данных
- ✅ Конфигурация прокси

## 🔧 Получение токена бота

1. Напишите @BotFather в Telegram
2. Отправьте команду `/newbot`
3. Следуйте инструкциям
4. Скопируйте полученный токен в `.env`

## ✅ Проверка работы

После запуска бота:
1. Найдите бота в Telegram по имени
2. Отправьте `/start`
3. Если вы админ (ID: 1048782601) - увидите админскую панель
4. Если обычный пользователь - увидите кнопку получения VLESS ссылки

## 🆘 Проблемы?

- **Ошибка импорта:** `pip install -r requirements.txt`
- **Не работает IP:** `python test_ip.py`
- **Проблемы с правами:** Запустите от имени администратора
